### Taintless Studio

We build Taintless Phone, a phone system for FiveM servers running QBX, QBCore, ESX, or standalone.

Each player's number lives on a physical SIM card and their data lives in a Cloud account, so neither is tied to a single handset. Move the SIM into another phone and sign in, and the number, conversations, mail, and installed apps come with it. If the SIM is lost as well, the in-city telecom dealer reissues it for the same number and the old card stops working.

For server owners, the resource ships with readable source, migration tools for supported phone systems, and a versioned Custom Apps API, so custom apps live in their own resources instead of the phone core.

Taintless Phone is in Early Access and under active development.
